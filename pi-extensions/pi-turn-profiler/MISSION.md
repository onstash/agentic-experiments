# Mission: Build Useful Pi Extensions

## Why
Build polished Pi extensions that improve real coding sessions, then develop enough confidence to design and publish original extensions like context visualizers, checklists, and usage meters.

## Success looks like
- Build a working extension from Pi lifecycle events and commands
- Add useful terminal UI without copying an entire existing project
- Preserve extension state safely across session reloads
- Package and publish an extension that other Pi users can install

## Constraints
- Lessons must be short, practical, and ADHD-friendly
- Each lesson must produce one visible result
- Prefer Pi's built-in APIs over extra dependencies

## Out of scope
- Custom model providers and OAuth until the extension fundamentals are solid
- Complex context rewriting in the first project
