# Pi Extension Development Resources

## Knowledge

- [Pi extension documentation](https://github.com/earendil-works/pi-mono/blob/main/packages/coding-agent/docs/extensions.md)
  Primary API reference for events, commands, tools, state, and UI. Use for every extension API decision.
- [Pi TUI documentation](https://github.com/earendil-works/pi-mono/blob/main/packages/coding-agent/docs/tui.md)
  Primary reference for status indicators, widgets, overlays, components, input, and rendering constraints.
- [Pi extension examples](https://github.com/earendil-works/pi-mono/tree/main/packages/coding-agent/examples/extensions)
  Maintained working examples. Use to find the smallest official pattern before writing custom infrastructure.
- [Official status-line example](https://github.com/earendil-works/pi-mono/blob/main/packages/coding-agent/examples/extensions/status-line.ts)
  Closest primary-source example for the first project's persistent footer indicator.

## Wisdom (Communities)

- [Pi Discussions](https://github.com/earendil-works/pi-mono/discussions)
  Ask extension-design questions and compare behavior with other Pi users.
- [Pi extension ecosystem](https://github.com/championswimmer/pi-context-usage)
  A concrete production extension to study after the minimal lifecycle lesson works.
