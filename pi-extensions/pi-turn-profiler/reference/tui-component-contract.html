Quick reference

Pi TUI component contract

A component turns available width and input into terminal lines and actions.

Minimum shape

class Panel {
  render(width: number): string[] { return [] }
  invalidate(): void {}
  handleInput?(data: string): void
}

Non-negotiable rule

Every rendered line’s visible width must be less than or equal to the width passed to render().

const clipped = truncateToWidth(text, width)
const columns = visibleWidth(clipped)

ANSI color codes occupy bytes but no terminal columns. Use visibleWidth(), not string.length, when padding styled text.

Overlay pattern

await ctx.ui.custom(
  (_tui, theme, _keys, done) =>
    new Panel(theme, () => done(undefined)),
  { overlay: true },
)

Interaction defaults

  • Close temporary panels with Escape.
  • Use matchesKey(), not raw escape sequences.
  • Do not animate keyboard-driven overlays.
  • Snapshot displayed data when opening unless live updates are required.
  • Rebuild theme-colored caches in invalidate().
