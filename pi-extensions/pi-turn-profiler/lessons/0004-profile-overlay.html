Turn data into a terminal interface

Win: /profile opens a centered, keyboard-dismissible panel instead of a temporary notification.

The component contract

A Pi TUI component is intentionally small. It renders terminal lines, optionally handles input, and invalidates cached output when needed.

render(width: number): string[]
handleInput(data: string): void
invalidate(): void

The critical constraint from the official TUI documentation: no returned line may exceed the supplied width.

Width is not string length

Theme colors add invisible ANSI control bytes. JavaScript’s string.length counts those bytes, but the terminal does not display them as columns.

truncateToWidth(text, availableColumns)
visibleWidth(styledText)

The overlay clips content before padding it. That keeps borders aligned when the terminal narrows or text contains color codes.

Open the overlay

await ctx.ui.custom(
  (_tui, theme, _keys, done) =>
    new ProfileOverlay([...history], theme, () => done(undefined)),
  { overlay: true },
)

[...history] takes a shallow snapshot. The panel displays the data that existed when it opened rather than sharing a mutable array with the extension.

Why there is no animation

This panel is opened from a keyboard command and may be used frequently. It appears immediately and closes immediately. Polish here means low latency, aligned text, predictable keys, and correct terminal resizing—not decorative motion.

Retrieval check

Why does the renderer use visibleWidth() instead of string.length to calculate padding?

Styled strings contain invisible ANSI bytes. visibleWidth() measures displayed terminal columns, so padding and borders remain aligned.
