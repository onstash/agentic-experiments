# Create or update a pull request

Inspect the branch diff against its base before opening or updating a PR.

## Required content

- Accurate title using Conventional Commit style when the repository uses it.
- Summary of the user-visible change.
- Verification commands and results.
- Known limitations and follow-up work.
- No literal escaped newlines in the body.

Register the full PR URL with the host orchestration system when available.
