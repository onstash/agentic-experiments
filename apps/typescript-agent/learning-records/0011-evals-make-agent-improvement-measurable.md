# Learning Record 0011: Evals Make Agent Improvement Measurable

## Date

2026-08-01

## What The Learner Is Ready For

The learner now has:

- a streamed agent runtime
- step-level evaluation
- a decision protocol
- a desire to understand how to improve the agent itself

## New Insight

Evals are not the agent's inner monologue. They are external tests that measure whether the agent is getting better at the jobs we care about.

## Why It Matters

Without evals, changes are mostly anecdotal. With evals, the team can detect regressions, compare versions, and choose improvements based on evidence.

## Next Step

Teach the difference between runtime step evaluation and offline evals, then connect both to the GitHub opportunity finder's ranking behavior.
