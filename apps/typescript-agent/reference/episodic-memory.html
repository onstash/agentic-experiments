Minimum Fields

Field Purpose
Query What the user asked
Steps Decisions and tool calls
Results Evidence returned by tools
Evaluations What each result meant
Outcome Final assistant summary
Stop reason Why the loop ended

Memory Boundaries

  • Episodic: what happened in one run
  • Working: what matters during the current run
  • Semantic: durable facts across runs
  • Procedural: durable ways of operating
