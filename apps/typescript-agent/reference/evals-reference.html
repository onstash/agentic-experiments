Evals

A compact guide to what evals are for and how they help an agent improve without guesswork.

Core Idea

An eval is a repeatable test for an agent behavior. It asks: did the system do the right thing, in the right way, for the right reason?

What Gets Measured

  • task success
  • answer quality
  • tool selection
  • latency and cost
  • regressions after a code change

Why It Helps

without evals: "it feels better"
with evals:    "it won on 82/100 cases"
