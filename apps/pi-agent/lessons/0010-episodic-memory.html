Lesson 10

Persist Episodic Memory

A streamed run disappears when the process exits. Episodic memory preserves what happened so the agent can inspect its past later.

Progress

Lessons 1–9 are studied and learned. The runtime now produces a trace of decisions, tool calls, results, evaluations, and completion.

What Episodic Means

Episodic memory records a specific event or run. It answers:

  • What did the user ask?
  • What did the agent do?
  • What did the tools return?
  • Why did the run stop?

It is a historical record, not a permanent fact about the world.

Important Boundary

Episodic memory records what happened. It does not automatically change future behavior. Later lessons will decide how to read it and whether to extract durable knowledge.
